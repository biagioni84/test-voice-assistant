# Oficina (documento de ejemplo genérico)

Este es contenido de relleno para probar el RAG hasta tener los documentos reales.

La oficina abre de lunes a viernes de nueve de la mañana a seis de la tarde. Los sábados abre solo de diez a una de la tarde y los domingos permanece cerrada.

El wifi de invitados se llama "Invitados-Oficina" y la contraseña cambia cada mes; se pide en la recepción. La red interna solo se puede usar con equipos registrados por el área de sistemas.

Las salas de reunión se reservan desde el calendario compartido. Hay tres salas: la sala Norte tiene capacidad para diez personas, la sala Sur para seis y la sala Café para cuatro. Las reservas se pueden hacer con un máximo de dos horas seguidas.

El estacionamiento para bicicletas está en la planta baja, junto al ascensor. Los autos deben registrarse con anticipación porque hay solo doce lugares.
